# 🐧 Super Tux Catch (STC)

Super Tux Catch is a 3D platform game developed with the Godot Engine, where you embark on an adventure with Tux to collect fish on a snowy, icy island! 

Developed under the Free and Open Source Software (FOSS) philosophy, the goal of this project is to collect all the fish scattered across the map in the shortest time possible and achieve a high score.

## 🎮 Game Features
* 3D Open Island Map: A vibrant world filled with snowy mountains, pine trees, and igloos!
* Dynamic Controls: Touch-screen virtual joystick optimized for mobile devices and smooth camera movements.
* Open Source (FOSS): The game is entirely developed under free software principles.

## 🕹️ How to Play
* Use the virtual joystick on the left to guide Tux.
* Collect the fresh fish scattered all around the map.
* Race against time to break your own record!
